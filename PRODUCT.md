# Product context for documentation

Meada builds deterministic code graphs across repositories using tree-sitter and explicit
contracts. Indexing is local and network-free. People and coding agents query the map through
three read-only MCP tools. Optional server modules support shared deployments.

This context records the founder's explicit #320 brief, not a new product decision. Developers
need to install, configure and query Meada; operators need to deploy and understand admission,
generations and the console. The documentation is Portuguese first with complete English and
Spanish equivalents. S1 and S2 are delivered; S3, S4 and S5 remain planned.

The new web surface is GitHub Pages at `/meada/`, built on MkDocs Material. The requested visual
quality is modern, deliberate and suitable for long technical reading. The console's existing
green accent is incumbent evidence; the console itself is outside this change. Preserve every
README section, examples and caveats, ADRs and product invariants. Avoid a marketing landing
page, default Material styling and default diagram styling. React Flow powers custom read-only diagrams and a roadmap, with local bundles and accessible static/text fallbacks. Long operational reading is divided by meaningful step exploration. No additional design interview is
needed: this direction and the scope were explicitly settled by the founder.
