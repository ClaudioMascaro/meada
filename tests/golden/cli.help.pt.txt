Grafo de código sem LLM para agentes e pessoas

Usage: meada <COMMAND>

Commands:
  index   Constrói os índices do workspace do repositório no diretório atual.
  status  Mostra o workspace: cada repositório, o estado do índice e os pares não encontrados.
  export  Imprime o índice como JSON ordenado, com os links que o tocam.
  mcp     Serve o repositório do diretório atual a agentes por MCP (stdio).
  decide  Resolve os itens abertos deste repositório, links ambíguos e URLs dinâmicas, e registra as escolhas em meada.decisions.toml.
  help    Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version
