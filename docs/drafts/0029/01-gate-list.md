## Usage questions

A pair enters the gate when a report recorded in the tracker found a wrong statement of it, or when a usage question recorded here is answered by reading it.

1. Which CI jobs, in which repositories, call the reusable pipelines and the actions a team publishes?
2. Which repositories consume the APIs and the packages a team publishes?
3. Does an agent answer more questions right with the Meada MCP server than without it?
4. Which provisioned infrastructure and which images have no use, no provisioner, no builder or no runner?

Question 3 names no pair of its own: an agent reads the statements of every pair. It puts nothing in the gate, and its measurement is not a yardstick.

## The stop rule today
