# Meada 1.3.0

[Português (Brasil)](1.3.0.md) · **English** · [Español](1.3.0.es.md)

1.3.0 is a minor release under the [1.x stability promise](../site/en/stability.md): no frozen item
breaks. Infrastructure joins the graph: what the repositories declare in Terraform, Kubernetes,
Compose and the other formats below is indexed and linked to the code that uses it. The tree
declares **1.3.0** (workspace, the `meada-core` pin, Dockerfile, compose defaults and Helm chart),
and the `v1.3.0` tag goes on the `release/1.3` branch, cut from the merge of the PR that carries
these notes on main. Publishing the crates, the staged npm package and the GitHub draft release
belongs to the maintainer. The detailed changes are in the [CHANGELOG](../../CHANGELOG.md).

## Changes

- **Config values** (ADR 0025; [#639](https://github.com/ClaudioMascaro/meada/issues/639),
  [#640](https://github.com/ClaudioMascaro/meada/issues/640), [#647](https://github.com/ClaudioMascaro/meada/issues/647)):
  every scalar of the YAML, JSON, Terraform and OpenTofu files the walk visits is indexed with its
  file, key path, type and line. `search` finds them with the new kind `value`. A value over 1 KiB
  is stored cut, and a Kubernetes `Secret`, a sensitive Terraform variable and an SSM
  `SecureString` are stored as `redacted`. Values stay out of `meada export`.
- **IaC nodes** (ADR 0025; [#649](https://github.com/ClaudioMascaro/meada/issues/649) to
  [#655](https://github.com/ClaudioMascaro/meada/issues/655), [#642](https://github.com/ClaudioMascaro/meada/issues/642)):
  Terraform and OpenTofu resources, data blocks and module calls (HCL and JSON), Compose services,
  CloudFormation and SAM resources, Serverless Framework functions, Kubernetes objects with
  Kustomize overlays, and Crossplane compositions are nodes with an address, a type and
  references. `search` finds them with the new kind `iac`, `context` shows their references and
  values, and `trace` walks the references both ways. Terraform names, `count` and `for_each` are
  evaluated statically, without running Terraform or reaching the network; a part Meada cannot
  know is a `*` and the name a pattern.
- **Infrastructure contracts** (ADR 0026; [#656](https://github.com/ClaudioMascaro/meada/issues/656),
  [#658](https://github.com/ClaudioMascaro/meada/issues/658), [#667](https://github.com/ClaudioMascaro/meada/issues/667),
  [#669](https://github.com/ClaudioMascaro/meada/issues/669), [#671](https://github.com/ClaudioMascaro/meada/issues/671)):
  the queues, topics, streams, buckets, tables, databases, parameters and secrets that Terraform
  and OpenTofu declare on AWS, GCP and Azure are provisioners of the contract their physical name
  gives, and every producer, consumer, writer and reader links to them. Curated Kubernetes
  operators (Strimzi, RabbitMQ, ACK, Config Connector, Crossplane) and six `terraform-aws-modules`
  sources provision too, and `meada.toml` maps private module sources and custom kinds to them.
  `meada status` lists provisioners without uses and uses without provisioners, only where the
  visible scope holds both sides ([#657](https://github.com/ClaudioMascaro/meada/issues/657)).
- **SDK use sides** ([#659](https://github.com/ClaudioMascaro/meada/issues/659),
  [#660](https://github.com/ClaudioMascaro/meada/issues/660), [#668](https://github.com/ClaudioMascaro/meada/issues/668),
  [#670](https://github.com/ClaudioMascaro/meada/issues/670), [#719](https://github.com/ClaudioMascaro/meada/issues/719)):
  calls of the AWS, GCP and Azure SDKs in TypeScript, JavaScript, Python, Java, Go and C# are
  sides of those contracts, DynamoDB transactions included. A literal name or ARN links `exact`;
  a name read from the environment stays unresolved and names its variable. Config values that
  name an AWS resource (an ARN, a queue URL, an S3 URI) are uses as well
  ([#661](https://github.com/ClaudioMascaro/meada/issues/661)).
- **Images and workloads** ([#662](https://github.com/ClaudioMascaro/meada/issues/662),
  [#663](https://github.com/ClaudioMascaro/meada/issues/663), [#664](https://github.com/ClaudioMascaro/meada/issues/664),
  [#667](https://github.com/ClaudioMascaro/meada/issues/667), [#669](https://github.com/ClaudioMascaro/meada/issues/669)):
  image contracts link builders (GitHub Actions, Compose, Skaffold, ko, Jib) to runners
  (Kubernetes, Compose, Helm, Lambda, ECS, Cloud Run, Azure Functions), and `trace` crosses from
  a workload into the code it runs. An environment read resolves through the workloads that run
  its code, ConfigMap references and Compose defaults included.
- **HTTP** ([#665](https://github.com/ClaudioMascaro/meada/issues/665),
  [#666](https://github.com/ClaudioMascaro/meada/issues/666), [#685](https://github.com/ClaudioMascaro/meada/issues/685)
  to [#690](https://github.com/ClaudioMascaro/meada/issues/690)): API Gateway, SAM and Serverless
  routes are providers; a base URL follows Kubernetes Service DNS names, Ingress hosts and Compose
  service names to the repository that serves them. TypeScript reads `new URL(..)` and sealed
  class fields, Go a struct field that keeps a base URL, and Backstage `$include`, `$env` and the
  legacy proxy shape.
- **Alerts** ([#672](https://github.com/ClaudioMascaro/meada/issues/672),
  [#673](https://github.com/ClaudioMascaro/meada/issues/673)): alert contracts join the labels of
  Prometheus, Loki, PrometheusRule and Grafana rules to Alertmanager route matchers, and Datadog monitor tags to OpsGenie routing; a selected
  Alertmanager receiver carries rule labels into OpsGenie tags or PagerDuty v2 custom details.
  Equality is `exact`; a regular expression, a prefix or a containment is `inferred`.
- **Open names and decisions** ([#674](https://github.com/ClaudioMascaro/meada/issues/674),
  [#641](https://github.com/ClaudioMascaro/meada/issues/641)): an unresolved name with enough
  literal anchors links to its counterparts, and a choice among several replays from
  `meada.decisions.toml`. A declared resource's `via` accepts an IaC address or
  `<file>#<key path>`.
- **Console** ([#675](https://github.com/ClaudioMascaro/meada/issues/675)): the graph has views
  for image builders and runners, alert emitters and matchers, and provisioners, with a legend
  and keyboard navigation; the playground has the `value`, `iac` and `alert` searches.
- **Refresh** ([#610](https://github.com/ClaudioMascaro/meada/issues/610),
  [#611](https://github.com/ClaudioMascaro/meada/issues/611), [#711](https://github.com/ClaudioMascaro/meada/pull/711)):
  a refresh reads the values of unchanged files from a cache beside the index (`values.db`,
  ADR 0027) and summarizes a contract configuration again only when what it read changed. On
  Meada's own repository, a one-line edit of a Rust file refreshes in about 1 s, where it took 3.4 s (1.4 s with the values cache, then 1.0 s).
- **Fixes**: `meada mcp` over stdio answers calls sent without waiting for each reply, where a
  refresh failed with `database is locked` ([#704](https://github.com/ClaudioMascaro/meada/issues/704));
  Terraform evaluation follows Terraform on sets, objects, numbers and conversions, and charges
  what a `for` costs before running it ([#711](https://github.com/ClaudioMascaro/meada/pull/711),
  [#714](https://github.com/ClaudioMascaro/meada/issues/714), [#720](https://github.com/ClaudioMascaro/meada/issues/720),
  [#740](https://github.com/ClaudioMascaro/meada/issues/740)); a Java AWS request no longer names a
  resource its builder had before it changed ([#719](https://github.com/ClaudioMascaro/meada/issues/719));
  crafted IaC, YAML and Alertmanager files no longer exhaust memory or time
  ([#646](https://github.com/ClaudioMascaro/meada/issues/646), [#672](https://github.com/ClaudioMascaro/meada/issues/672),
  [#711](https://github.com/ClaudioMascaro/meada/pull/711)); and commands that print once done
  no longer panic when the reader closes early (`meada export | head -1`).

## Upgrade notes

- **Index**: the schema changed, so an existing index is rebuilt once on first use. A `values.db`
  file appears beside it: it is a cache, and deleting it costs only time. The index grows with the
  config values: their substring search table holds about four times their text.
- **Helm values files**: any YAML file with a `values` word in its name is Helm input
  (`prod-values.yaml` is, `valuesets.yaml` is not), for image runners and for alerts.
- **GitHub App** ([#452](https://github.com/ClaudioMascaro/meada/issues/452)): `github-app roles` treats a
  403 `Resource not accessible by integration` with quota left as a permission failure and
  records the repository as `forbidden`, where it throttled.
- **Search**: the kinds `value`, `iac`, `image` and `alert` are new. The default search answers with config
  values only when no symbol and no contract matches, and leaves IaC nodes out.
- **Export**: the format stays 1. It gains the optional arrays `iac_nodes`, `provisioners`,
  `provisions`, `uses`, `executions` and `subscriptions`, an optional `via` and `at` on providers
  (the SDK origin or environment read; the configuration location of a repository-level side such
  as an image builder), an optional `root` on consumers and an optional `at` on provisions.
- **Links that change**: some links that were `exact` are now `inferred` or unresolved, where
  the earlier answer could name what the code does not touch: an AlertmanagerConfig route (its
  namespace is not read), a Compose path a deployer can override, a Java AWS request built from
  a builder that changes, a TypeScript or Go request changed after it is made, a Serverless
  function with no `name`, and the Terraform cases of the CHANGELOG. An Alertmanager configuration
  with a matcher regex Go refuses is unreadable as a whole, as Alertmanager refuses to load it
  ([#718](https://github.com/ClaudioMascaro/meada/issues/718)). In Java, Go and C#, an EventBridge entry without
  `EventBusName` produces to `default` and an SNS publish to a phone number names no topic.
  Kustomize references between bases with their own `namePrefix` resolve as Kustomize does, and a
  Helm `image.registry` prefixes the runner's image. An HTTP route that overlays
  repeated per environment is no longer `ambiguous`: a decision recorded for it is stale, and
  `meada decide --prune` removes it.
- **Console authorization with GitHub** ([#454](https://github.com/ClaudioMascaro/meada/issues/454)):
  under `[oidc.github]`, the console stamps each `added_by` it writes with `added_by_time`.
  Entries saved before this version carry no time, so their additions are excluded until the
  global operator writes a reviewed `added_by_time` or a team operator adds them again. Postgres
  migration 10 adds `<schema>.permission_state`: run `meada postgres migrate` before starting 1.3.0
  (the Helm chart's migrate job and the Compose `postgres-migrate` service do it). Once migrated,
  1.2.0 binaries refuse the schema, so upgrade every console, node and job together; there is no
  rollback to 1.2.0.
- **`meada-core` crate users** (the Rust API is not frozen): `ids::VersionEntry` gains a sixth
  element and `ids::NON_BLOCK_KEYS` a fifth key, both for `added_by_time`;
  `authorize::compose_entries` takes `now` as its fourth parameter, and so does the JavaScript
  `composeEntries`; `manifest::EntryFile` gains the public field `added_by_time`; the export
  structs gain fields. To stay on 1.2, pin `meada-core = "~1.2"`.
- **Compose and Helm**: the defaults point at `1.3.0`. If you pin `MEADA_VERSION` or the chart
  version, change it when you upgrade.

## Publication checklist

### Before the tag

- [ ] `chore(release): 1.3.0` PR green in CI and merged by the maintainer.

### Maintainer publication

- [ ] Tag `v1.3.0` on that merge commit, on a new `release/1.3` branch, and push both; this
  triggers `release.yml` (the cargo-dist draft and the job that stages the npm package).
- [ ] Publish the crates: `meada-core` first, then `meada`.
- [ ] Review the draft and publish the GitHub release; this triggers `container.yml` (images,
  Helm chart and `meada-ui-1.3.0.tar.gz`).
- [ ] Approve the staged npm package with 2FA (`npm stage list @meada/meada`, then
  `npm stage approve <id>`), only after the release is published: the npm installer downloads
  the binary from `releases/download/v1.3.0`, which answers 404 while the release is a draft.

### After publication

- [ ] `npx @meada/meada --version` reports `1.3.0`, and `docker pull ghcr.io/claudiomascaro/meada:1.3.0`
  and `:1.3.0-cloud` work.
